2. GAME ROUNDS AND SCORING
==================================================

Difficulty increases in this order:

WARM UP < SURVIVAL < MANDATORY < BATTLE

Scoring:

WARM UP:
+1 point for a correct answer

SURVIVAL:
+2 points for a correct answer

MANDATORY:
+3 points for a correct answer

BATTLE:
+5 points for a correct answer

Create one clear scoring configuration, for example:

const ROUND_POINTS = {
  "WARM UP": 1,
  "SURVIVAL": 2,
  "MANDATORY": 3,
  "BATTLE": 5,
};

Do not store duplicated scoring values in multiple components.

3. PLAYER MODEL
==================================================

Extend the player model to contain:

id
name
avatarId
points
lives
active

Every player starts with:

points = 0
lives = 2
active = true

Correct answer:

- add points based on the current round,
- keep the player active,
- move to the next active player.

Wrong answer:

- subtract one life,
- points are not subtracted,
- when lives reach 0, set active = false,
- move automatically to the next active player.

Lives must never become negative.

The game ends when only one active player remains.

Store the winner in the game state and show a clear English winner message.

Handle the edge case where no active players remain without crashing.
